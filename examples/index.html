About Polytree

Polytree is a modern, high-performance Constructive Solid Geometry (CSG) library enhanced with advanced spatial query capabilities. These examples demonstrate real-world applications from basic CSG operations to complex spatial analysis perfect for 3D printing and CAD workflows.

Key Features Demonstrated

These examples showcase Polytree's transformation from a pure CSG library into a comprehensive spatial querying tool. The spatial query capabilities are inspired by mature libraries like three-mesh-bvh but optimized for Polytree's octree-based architecture.

🏭 3D Printing Applications

  • Layer Slicing: Automated layer generation for FDM/SLA printing
  • Support Analysis: Intelligent support structure placement using distance queries
  • Volume Calculations: Accurate material estimation with both exact and statistical methods
  • Quality Control: Surface analysis and collision detection

🔬 Technical Advantages

  • Unified Architecture: CSG + Spatial Queries in one optimized library
  • Octree Foundation: Leverages existing spatial partitioning for maximum performance
  • Multi-Input Support: Works directly with Three.js meshes, geometries, and Polytree instances
  • Memory Efficient: Automatic cleanup and smart resource management
